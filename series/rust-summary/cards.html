2 / 8
第 1–7 课
基础语法 + 所有权（上）
01
知识全景五块知识一层层搭，先吃透所有权
02
let · mut · shadowing默认不可变；改值加 mut，换类型再 let 一次
03
基本类型整数默认 i32，浮点默认 f64；不会偷偷转换
04
函数与表达式最后一行不加分号，就是返回值
05
控制流if 能直接赋值；loop / while / for 各管一种
06
所有权三条规则一个主人；同时只有一个；主人走了值就释放
07
Move · Clone · Copy搬走、手动复制、自动复制：看旧变量还能不能用
3 / 8
第 8–14 课
借用、建模、错误处理
08
借用 & 和 &mut要么多个只读，要么一个能改，不能同时
09
String 和 &strString 拥有能改；&str 只借一段来看
10
struct + impl没有 class：struct 放数据，impl 放方法
11
enum + match每种情况都得处理，漏一个就编译不过
12
Option没有 null：「可能没有」写进类型里
13
Result 和 ?没有异常：错误是值，? 把错误交给上层
14
Cargonew · run · add · test，四个命令走完一个项目
4 / 8
第 15–20 课
抽象 + 实战
15
trait一份行为清单，一个参数收下所有实现它的类型
16
泛型<T> 一份代码多种类型，编译时展开不变慢
17
生命周期 'a不改变寿命，只告诉编译器引用跟谁一样久
18
迭代器和闭包map / filter 串成链，collect 才真正执行
19
clap 命令行写个 struct，参数解析和 --help 自动生成
20
reqwest + serde发请求，JSON 直接变成你的 struct
学完 20 课，你能：读懂编译器报错 · 写带测试的项目 · 做一个调 API 的命令行工具
