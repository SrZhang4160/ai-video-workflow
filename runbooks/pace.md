# 中文语速标准（所有系列、所有视频）

**每一句（每个字幕页 = 一段配音）都在 305–330 字/分钟之间，整条视频听起来速度均匀。**
适用于克隆声音、本人录音、AI 兜底配音；Rust、AI 工程师、系统设计（含短剧）、AI 快讯全部一样。英文不在此标准内（英文仍按 `render.py` 的 `PACE` 放慢）。

2026-11-04 实测（改之前）：531 句里只有 12 句达标，平均约 230 字/分，大部分 170–290，太慢。

## 怎么算
| 项 | 规则 |
|---|---|
| 字数 | 念出来的音节：汉字 1；数字每位 1（`%` 另加 3，百分之）；全大写缩写每个字母 1（API = 3）；其他英文单词按元音组（Claude = 1，token = 2） |
| 时长 | 这一句的配音，去掉开头结尾的气声和底噪，句内停顿算在内；页与页之间的停顿不算（那是 `PACE` 的间隔，中文 0.06–0.2 秒） |
| 语速 | 字数 ÷ 时长 × 60 |
| 达标 | 305 ≤ 语速 ≤ 330 |
| 不评判 | 少于 4 个字的句子（如「对。」），太短没法公平计时 |

代码：`engine/pace.py`（`zh_chars`、`LOW` / `HIGH` / `TARGET = 318`）。

## 渲染时自动执行
`engine/render.py` 对每一句中文配音：
1. **收紧**：剪掉首尾的气声/底噪；句内超过 0.25 秒的停顿缩成 0.18 秒（逗号是换气，不是停顿）。
2. **匀速**：还不在 305–330 之内的，用 atempo（不变调）调到 318 字/分；调速范围 0.8×–1.6×。

所以不需要重新配音，重新渲染就会达标。超出 0.8×–1.6× 才能达标的句子标为 **需重配**：通常是克隆声音切错了（一句太短、被截断），或者一句话里拖了很长的戏剧停顿。

## 逐句审查
```
~/cosyvoice3/.venv/bin/python engine/pace.py                       # 现在的配音，逐句：太慢 / 太快 / 达标
~/cosyvoice3/.venv/bin/python engine/pace.py --after               # 渲染后的语速（成片会是这样）
~/cosyvoice3/.venv/bin/python engine/pace.py episodes/<id> --after -v   # 一期，每句都列出来
```
结果也写到 `build/pace-audit[-after].json`。

## 出片前（nightly 第 2、3 步）
- 跑 `pace.py episodes/<id> --after`。
- 有 **需重配** 的句子：播出日期不近 → 改这句的 `say_zh`（去掉句中冒号/戏剧停顿、合并太短的句子），重新 export，让 Mac 重配这一句；日期近 → 写进 `review_notes`：`第 N 句语速调不进 305–330，请听一下：<那一句>`。
- 写脚本时（`runbooks/scenes.md`）：每页不要太短（≥ 4 字），少用「冒号 + 一个字」这种拖停顿的写法，比如「技术总监说：够。」。

## 本人录音（AI 快讯）
照平常语速念就行，渲染时一样逐句调到 305–330。录得太慢超过 1.6× 的句子会被标出来，请补录那一句。
