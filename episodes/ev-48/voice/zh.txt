这期来讲，为什么模拟出来的顾客太“好说话”。
用大模型扮演顾客来考 agent，又快又省。
可它演出来的顾客，和真人差得不少。
这期就来说说差在哪，分数又会怎么偏。
先说第一个差别，它太有耐心了。
Google 的研究团队在一篇博客里指出，
模拟用户常常耐心得不太正常，
而且客气得有点过了头，不像真人。
原因在于，大模型本来就被训练成
一个乐于助人、脾气很好的助手。
让它去演急躁、难缠的顾客，反而演不像。
放到我们的退款 agent 上来看，
agent 把同一个问题，翻来覆去问了好几遍，
模拟顾客照样客客气气地回答。
换成真人，可能早就不耐烦，直接走了。
agent 的毛病，就这样被它包容了过去，
测出来的分数，就比真实情况更高。
第二个问题，是由谁来演这个顾客。
I C L R 二零二六上有一篇论文，叫 Lost in Simulation，
拿 tau bench 的零售题做了一组实验。
同一个 agent，换不同的大模型来演顾客，
成功率最多能差九个百分点。
这篇论文还请了四个国家的真人做对照，
发现模拟顾客对难度的判断也有偏差。
难题上，它把 agent 的表现估低了，
到了中等难度的题，又把它估高了。
所以分数里有一部分，测的其实是演员。
那该怎么办呢？主要有这么三个办法。
先是拿真实的对话，来校准模拟顾客。
从线上抽一批真人和 agent 的对话，
比一比模拟顾客的耐心和放弃的时机，
差得多，就回头去改它的提示词。
再是把演顾客的模型固定下来。
因为换了演员，分数一变，
你就分不清是 agent 变了，还是演员变了。
最后，就是专门加上几种难缠的顾客，
比如说不清订单的，被拒了还坚持要退的。
所以说，模拟顾客默认太好说话，分数会虚高。
拿真人校准，再固定演员、加难缠角色，
这样模拟出来的分数，才更接近真实。
