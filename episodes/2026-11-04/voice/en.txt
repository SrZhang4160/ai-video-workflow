One of the most common crashes: a null reference.
Rust has no null at all. Why?
The type won't say it can be null. Miss a check, it crashes.
Rust uses an enum from last lesson: Option.
Either Some, holding a value, or None.
The key: an Option of i32 is not an i32.
Try to add it directly? It won't compile.
The type says it: there may be no value.
The compiler makes you handle the None case first.
How do you get the value out? With match, from last time.
Write both Some and None, or it won't compile.
Only care about the value?
Use if let. It runs only when there is a value.
Want a default? Use unwrap or.
unwrap panics on None. Use it sparingly.
To sum up: null hides and crashes at runtime.
Option lives in the type, so the compiler checks it.
