第三方 AI agent 帮人在 DoorDash 点外卖，
到现在一共才几百单。
而 DoorDash 上个季度：9.93 亿单。
这是 CEO 在 10 月 29 日财报会上说的，
提到的 agent 有 Meta 的 Muse、Instinct、Fo。
他说：别跟大势较劲，但也别自欺欺人。
DoorDash 在财报里说，它要赢的是「原子之战」：
仓储、无人配送，把东西真正送到门口。
AI 这边，它先做自己的 agent：
Ask DoorDash、短信下单、命令行下单。
CEO 还说，以后可能在外部 agent 里卖广告。
为什么这么少？官方没解释，但有两个事实：
一，大部分人还是在 App 里自己点；
二，给外部 agent 的门还很窄：
MCP 连接器只面向企业订餐，还在小范围测试，
而且要员工先登录、同意条款。
别家也分成两派：亚马逊开始拦 agent 替人下单。
沃尔玛反而开了 MCP 入口，但规矩很细：
agent 拿不到你的支付信息；
每个 agent 有单独身份，像信用卡附属卡；
每单可以审批，也能设花钱上限。
我的看法：接口已经有了，缺的是信任。
平台愿意放 agent 进来，但要按它的规矩。
做 agent 的话，先把审批和花钱上限做好。
一句话：路通了，单还没来。
接下来看：沃尔玛 agent 身份上线，
和 DoorDash 会不会公布 agent 订单数。
