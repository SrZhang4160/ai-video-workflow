MCP 是什么？agent 为什么需要它？
旅行助手要查天气、查景点、查路线。
这是三个外部服务，接口各不一样。
没有统一标准，每接一个就要写一个适配器。
适配器，就是对接某一个接口的专用代码。
换一个 AI 应用，这些适配器还得重写一遍。
MCP 全称 Model Context Protocol。
它是一套标准，规定应用和服务怎么对话。
外部服务按这套标准实现一次，
任何支持 MCP 的 AI 应用都能直接接上。
Host 是 AI 应用本身，比如这个旅行助手。
Server 是按标准提供能力的外部服务，
比如查天气的服务。
Client 是 Host 里负责连接的组件。
一个 client 只连一个 server，
所以三个 server，就要三个 client。
一个 server 能提供三类能力。
第一，工具：模型能调用，比如查天气。
第二，资源：可读的数据，如景点介绍。
第三，提示模板：用户可以直接选来用。
本质：MCP 是应用接外部服务的统一协议。
