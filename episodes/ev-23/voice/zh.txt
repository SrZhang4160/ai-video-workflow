行业里，都用什么工具做 agent 评测？
工具的名字一大堆，第一次看会觉得很乱。
其实按解决的问题，可以分成四类。
分清了类别，你才知道自己缺的是哪一块。
我们拿退款客服 agent 来看，每一类帮你做什么。
先看第一类，开源的评测框架。
它是一套代码库，帮你写考题、跑 agent、判分。
比如 Inspect，是英国 AI 安全研究所和 Meridian Labs 做的。
你用 Python，把题库、解题步骤和判分器拼起来。
它还自带沙箱，agent 在隔离的环境里跑。
再比如 promptfoo，只要写一份配置文件。
里面列出提示词、模型和考题，它就挨个去比。
它也能接进 C I，每次改动都自动跑。
还有 DeepEval，写评测就像写 py test 单元测试。
再看第二类，评测加上记录的平台。
只用框架的话，记录和结果都散在各处。
平台把记录、题库和每次的分数存在一起。
新旧版本的分数，可以并排对比。
它还能给线上的真实对话，自动打分。
比如 LangSmith，还有开源、能自己部署的 Langfuse。
第三类，是 agent 框架自带的评测。
有些搭 agent 的框架，本身就带评测功能。
比如谷歌的 A D K，能检查 agent 调工具的顺序。
它跟标准答案比，也会检查最后的回复。
OpenAI 的 Agents S D K，默认就把每一步记下来。
记录发到 OpenAI 的后台，可以在那里给它打分。
第四类是红队工具，专门来攻击你的 agent。
红队就是扮演坏人，故意去找安全漏洞。
比如英伟达的 garak，会自动发一批攻击提示词。
看它会不会被提示注入，会不会泄露数据。
微软的 PyRIT，promptfoo 的红队功能，也是干这个的。
那这四类工具，是怎么配合起来用的？
评测框架，负责写题、跑题和判分。
平台存下记录和结果，还给线上对话打分。
框架自带的评测，跟着你选的 agent 框架来。
红队工具，专门在上线前去攻击它。
所以说，这四类不是四选一，而是各管一段。
同一个退款 agent，完全可以四类工具一起用。
