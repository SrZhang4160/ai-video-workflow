新模型在榜单上分数第一，
换到你的 agent 上，就一定好用吗？
不一定。榜单考的是通用能力，
你自己的业务规矩，它一条都不考。
先看 S W E bench，考改开源项目的 bug，
改完跑项目自带的测试，全过才算对。
再比如 tau bench，考的是客服类任务。
一个模型扮顾客，跟被测的 agent 对话。
agent 照一份规则，用工具改模拟数据库。
最后查数据库的状态，和标准答案比对。
考 agent 时，每个模型套的是同一个外壳，
所以分数差，主要是模型的差。
还有考网页操作、电脑操作和调工具的。
它们测的，都是模型做 agent 的通用本事。
可你的退款客服，不只是一个模型。
它是模型，加上你写的提示词，
加上查订单、退款和发邮件这些工具，
还有你自己定下的退款规矩。
比如三十天内才能退款，
超过五百元要人工审批，
退之前还得核实，这单是不是他买的。
这些规矩，公开基准一条都不考。
可你的客服每天碰到的，恰恰就是这些。
而且基准的分数，本身也可能偏高。
题是公开的，题和答案可能混进训练数据。
模型可能背过答案，分数就不准了。
所以基准测的，是模型的通用本事，
agent 评测测的，是你这一整套系统。
那基准分数有什么用呢？用来初选模型。
分数明显偏低的，可以先排除掉。
但最后选哪个、改完有没有变好，
都得用你自己的评测集，一道道去量。
题从你的退款对话里来，按你的规矩判。
说白了，基准帮你挑模型，
你的 agent 好不好用，得用自己的题来测。
