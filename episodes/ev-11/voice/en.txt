Take the email a refund support agent sends the customer.
Code can't tell whether it's well written,
so a model judges it. That's an L L M judge.
This episode: how to write the rubric for the judge.
A rubric is the checklist the judge grades by.
In short: a single overall score can't be trusted.
Ask it for a score from one to ten, and "good" is never defined,
so the same email gets a seven, then an eight,
and a low score doesn't say what's wrong.
So split the rubric into small items, each asking one thing, answered yes or no.
Is the amount right? It must match the five ninety-nine order.
Does it say when the money arrives? Customers care most about these two.
Any off-policy promise, like a refund after thirty days?
Once said, the shop must honor it or apologize.
Is it polite? "Polite" is vague, so make it checkable:
did it apologize first, did it blame the customer?
Give the judge the order amount and the refund policy too,
or it can't tell whether the amount is right.
Have it write a reason before each yes or no,
so when it gets one wrong, you can see why.
If facts are missing, let it say "unknown" instead of guessing.
The email passes only if all four are yes; any no shows what to fix.
Asked in an interview how you'd write a judge's rubric? Say:
No overall score; each item is yes or no.
Give it the facts, and have it reason first.
If facts are missing, allow "unknown."
First step at work: take one reply your agent wrote,
and write four yes-or-no checks for it.
