# 2026-10-25 Rust 所有权（示例笔记）

## 今天学了什么
- Rust 里每个值只有一个所有者，所有者离开作用域，值就被释放。
- `let s2 = s1;` 之后 s1 就不能用了（String 被 move 了），但 i32 这种 Copy 类型不会。
- 想多处使用又不转移所有权 → 用引用 `&s1`（借用）。
- 同一时间：要么多个不可变引用，要么一个可变引用。

## 踩的坑
写了 `let s2 = s1; println!("{}", s1);`，编译报错 "borrow of moved value"。
一开始以为是 bug，后来才明白这是 Rust 故意的：防止两个变量同时释放同一块内存。

## 和我背景的联系
以前写机器人 C++ 时遇到过 double free，Rust 在编译期就挡住了。

## 想讲给别人的一句话
Rust 的所有权就是：一个东西只能有一个主人，想给别人看就「借」，借的规则编译器帮你管。
